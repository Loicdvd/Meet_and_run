# StrideLoop Brand Kit

## Brand Name
- `StrideLoop`

## Positioning
- Plan, share, and discover social runs with a route-first experience.

## Core Palette
- `Midnight Ink`: `#0B1B2B` (primary text, strong UI surfaces)
- `Route Green`: `#13B48A` (primary actions, active states)
- `Sunset Pulse`: `#FF7A45` (secondary actions, highlights)
- `Mist`: `#EAF4F6` (backgrounds, cards)
- `Slate`: `#4E6472` (secondary text)
- `Error Red`: `#C0392B` (errors)

## Gradient
- `Dawn Route`: `#13B48A -> #FF7A45`

## Icon Concept
- Circular badge with a diagonal route line between 2 pins:
- start pin in `Route Green`
- end pin in `Sunset Pulse`
- badge base in `Midnight Ink`

## Typography
- App UI: platform default sans for reliability.
- Weight usage:
- `700` headings and key actions
- `500/600` control labels
- `400` body text

## Voice
- Practical, social, outdoor-oriented.
- Clear route and timing language over marketing phrasing.
